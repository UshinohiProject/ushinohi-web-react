# Engineers-WEB
The website of [Ushinohi Project](https://ushinohi.com).  

This project is built with [Vite](https://vite.dev/).  
[![Netlify Status](https://api.netlify.com/api/v1/badges/2cbdf965-c088-4aea-ae42-1bf5dc52f282/deploy-status)](https://app.netlify.com/sites/goofy-kepler-e1a30e/deploys)

## Requirements

See [.nvmrc](.nvmrc) for the Node.js version (you can switch with `nvm use`).

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the development server.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

Changes are reflected in the page automatically when you save.

### `npm test`

Runs the tests with [Vitest](https://vitest.dev/) in watch mode.\
To run them once, use `npm test -- --run`.

### `npm run build`

Builds the app for production to the `build` folder.\
The build is minified and the filenames include the hashes.\
Your app is ready to be deployed!

### `npm run preview`

Serves the `build` folder produced by `npm run build` locally, so you can check the production build.
